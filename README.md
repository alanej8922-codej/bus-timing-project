# Bus Timing Project

A simple command-line app to store and look up bus timings for my home town, built with Python and SQLite.

## Features

- Add a bus timing (from, to, departure time)
- Search buses by starting place and destination
- View all buses
- Update a bus's departure time
- Delete a bus timing

## Tech

- Python 3
- SQLite (`sqlite3`, built into Python, so nothing to install)

## How to run

```bash
python main.py
```

The `bus.db` database file is created automatically on first run.

## Menu

```
1. add bus timing
2. search bus
3. view all buses
4. update bus timing
5. delete bus timing
6. exit
```
